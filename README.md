# 항해 Lite 백엔드 Step 1 (TypeScript)

### 시행착오 및 학습 내용

- 2025년 10월 19일
  1. TDD에 대한 이해가 없어서 기능 코드를 먼저 구현하였다. (192aa4d)  
     `실패하는 테스트 먼저 > 기능구현 > 테스트 > 코드 개선`
  2. TDD 자가진단표
  - 테스트가 필요한 이유를 말로 설명할 수 있는가?
    논리적인 결함하을 최소화 하고 안정성 있는 서비스를 제공하기 위해 필요하다.
  - 협업 시 테스트 코드가 어떤 역할을 하는가?
    개발 방향을 제시하는 가이드라인이 된다.
  - 테스트 가능한 구조를 만들기 위해 어떤 설계 전략이 필요한가?
    테스트를 무조건 먼저 작성한다.
    코드에 맞춰 테스트를 변경하는 것이 아닌 테스트에 맞춰 코드를 구현한다.
    (경험에 비추어 보았을 때 코드 구현 후 작성하는 테스트는 보여주기식 테스트가 될 수도 있을 것 같다.)
    Mock과 Stub 테스트를 동시에 진행하고 RED > GREEN > BLUE 단계를 따른다.
